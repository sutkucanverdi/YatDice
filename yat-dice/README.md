# 🎲 Yat Dice — Frontend (React 19 + TypeScript + Vite)

Bu dizin **Yat Dice** oyununun istemci (Web / Mobil PWA) uygulamasını içerir. Tüm proje mimarisi, backend kurulumu, API uç noktaları ve mağaza uyumluluk detayları için kök dizindeki ana [**README.md**](../README.md) dosyasına göz atın.

## 🚀 Hızlı Komutlar

```bash
# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat (http://localhost:5173)
npm run dev

# TypeScript kontrolü ve Production derlemesi (dist/)
npm run build

# Kod kalitesi / Linter kontrolü (Oxlint)
npm run lint
```
